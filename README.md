# solmara-pickup-line

One line for make.fun's "The Perfect Pickup Line" bounty: a million simulations of meeting you, and the opening line is forgotten in every one. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Bounty: https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6
